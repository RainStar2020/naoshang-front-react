## 真实 API 接入（2026-10-28）

- 后端：`http://localhost:3000/api/hq`。`npm run dev` 通过 Vite 同源代理转发，配置见 `.env.development`；生产部署须为 `/api/hq` 配置反向代理。
- 默认真实模式：登录、会话、25 个业务模块及账号设置均连接真实 API。`src/services/real/registry.ts` 绑定 118 个操作，另 2 个登录/注销由认证服务调用，共覆盖文档 120 个端点。
- `src/pages/LiveModule.tsx` 提供与后台契约一致的业务视图：读取列表/目录、分页、筛选、目标详情、相关记录、团队树、审计溯源和 CSV 下载；各模块复用界面组件，接口绑定仍逐模块明确声明。
- 写操作采用“业务参数 + action + 原因 + 版本 + 幂等号 → 核对 → 提交 → 服务端回执 → 刷新”。文档未定义的业务字段使用 JSON 参数编辑，不推断字段或金额公式；参数不完整时后端正常拒绝，不伪造成功。不自动重试，不自动创建测试业务数据。
- 金额直接使用后端“元”的 number，不沿用旧演示页面的分转元逻辑。详情失败不回退列表缓存或假数据；读取失败不退回 mock。
- 旧页面中后端未提供的操作不在真实页面开放：用户密码重置/换店、课程等级 CMS、软件卡供应商替换、协议版本、通用上传任务管理等。`/agents` 无对应 HQ 接口，显示未提供接口；`/course` 使用真实课程权益模块。后续需要后端新增契约后再实现这些旧功能。
- 账号设置入口位于右上角；改密接口的业务字段文档未定义，保留参数输入；改密成功清除旧会话。不会自动执行口令修改。
- `.env.test` 显式使用 mock 认证；`VITE_HQ_AUTH_MODE=mock` 时保留原演示模式。真实业务界面不调用旧 mock 服务，不再展示演示账号数据。
- 本地测试：`npm test`；真实只读回归：设置 `HQ_API_LIVE=1`、`HQ_API_PASSWORD` 后运行 `npm run test:api:live`；刷新空数据清单：设置 `HQ_API_PASSWORD` 后运行 `npm run audit:api:empty`。口令只通过当前进程环境变量提供，不写配置文件。

## HQ-02 用户账号与所属门店管理

- 入口：`/#/users`。按手机号/账号编号/昵称搜索，组合地区、所属门店（包括未绑定/已停业）和状态筛选；分页总数来自服务查询结果。地区选项目前仅有河南郑州、安徽合肥的演示数据，生产环境需由服务提供完整字典。

- 所有写入必须填写原因，携带版本及幂等请求号；成功后刷新列表并打开详情，展示操作人、请求号、时间、原因、前后结果。版本冲突需要刷新，重复提交不会产生多条操作记录。

## 核心：混排富文本编辑器（`components/RichEditor.tsx`）

### 块模型

正文由一组**块（Block）**按顺序组成，四类块：

| 块类型 | 渲染内容                                                               | 上传方式                                       |
| ------ | ---------------------------------------------------------------------- | ---------------------------------------------- |
| 文字块 | 可编辑文本（支持标题、加粗、斜体、下划线、颜色、列表、对齐、清除格式） | 默认空块，可通过底部「＋ 文字段落」追加        |
| 图片块 | 本地图片预览图，悬停可替换 / 删除                                      | 「＋ 图片」选择本地图片，转 Base64 内嵌        |
| 视频块 | `<video controls>` 播放器，显示文件名条与删除按钮                      | 「＋ 视频」选择本地视频，生成 `blob:` 预览地址 |
| 附件块 | 扩展名彩色徽标 + 文件名 + 大小 + 删除                                  | 「＋ 附件」选择文档 / 压缩包，转 Base64 内嵌   |

每个块悬停时显示 **↑ 上移、↓ 下移、× 删除**，实现「文字、图片、视频、附件」任意先后顺序的混排。

### 格式工具栏（聚焦文字块时生效）

正文 / 标题 1 / 标题 2 / 标题 3、加粗、斜体、下划线、无序 / 有序列表、左对齐 / 居中 / 右对齐、文字颜色、清除格式。

### 序列化输出

编辑器以受控组件形式提供：

```tsx
<RichEditor value={bodyHtml} onChange={setBodyHtml} height={460} />
```

`onChange` 实时返回可保存到后端的 HTML 片段：

- 文字块 → 内部 HTML（`<b>`、`<h2>`、`<ul>` 等）
- 图片块 → `<img src="..." alt="..." />`
- 视频块 → `<video src="..." controls playsinline></video>`
- 附件块 → `<a class="rich-file" href="..." download="...">文件名</a>`

再次打开编辑器时，`value` 中的 HTML 会被解析回上述块结构（`deserialize`），支持二次编辑。

### Demo 边界

- 图片与附件使用 Base64 内嵌，适合小图与文档；**视频使用 `blob:` 对象地址，刷新页面后失效**，仅用于本地预览。
- 文字格式基于 `document.execCommand`，适配桌面 Chrome / Edge；未实现行内图片尺寸拖拽、视频封面自定义、表格 / 表情插入。
- 未做图片压缩、格式 / 大小拦截、上传进度条；接入后端时见下方指引。

## 接入后端时的替换点

1. **文件上传接口**：替换 `RichEditor.tsx` 中图片 Base64、视频 `URL.createObjectURL`、附件 Base64 的生成逻辑，改为先调用上传接口拿到返回 URL，再构造对应块；`ImageUpload.tsx`、`FileList.tsx` 内的 `fileToBase64` / `URL.createObjectURL` 同样替换为接口上传。
2. **课程保存**：`CourseUpload.tsx` 的「发布课程」目前只做前端校验与成功弹窗；`bodyHtml`、`lessons`、`attachments`、`cover` 提交到课程保存接口即可。
3. **Mock 数据**：`src/mock/data.ts` 中的数组替换为接口返回；各页面目前用 `useState(mockXxx)` 初始化，可直接改为 `useEffect` + 请求。
4. **素材引用**：素材卡片「引用」当前为 Toast 占位，接入后可把对应图片 / 图文 / 视频插入当前编辑器选区位置。
5. **收益 / 合伙人 / 代理**：明细表数据与状态切换对接各自查询、更新接口。

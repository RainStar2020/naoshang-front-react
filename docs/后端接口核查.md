# 后端接口核查（2026-10-29）

依据：后端当前项目全量API文档及挂载模块实现。文档中的 H5、旧管理接口不自动混入 HQ 会话。

## 已修正

- 专栏操作使用 save/publish/offline，支持生成 columnId 新建；新建版本为 1。
- 支付操作保持 save-channel/query/compensate/reconcile 原名；保存配置补齐 platform/business/channel。

## 尚需接入或明确产品语义

- 激活码导出：POST /activation-codes/mutate action=export 已存在，返回完整码面；前端当前选择具体码，后端只按 batchId 或全量导出，需要选择过滤和审计范围设计。
- 支付导出：GET /payments/export 已存在，但并不是按 jobId 下载原始对账文件或差异文件；不能直接替换现有按钮。
- 专栏/资料 assets 仅登记素材元数据，不传输文件；真实上传存储链路仍待补齐。
- 区域代理独立 HQ 模块、账号重置密码/改编号、课程 CMS 保存及上传、商品分类/履约类型改名、履约策略保存、软件卡下载、支付样例及任务源文件/差异文件下载：当前 HQ 契约仍缺少对应能力。
- 公告、合伙人、商品素材上传缺少完整传输链路。

## Mock 核查

开发环境 VITE_HQ_AUTH_MODE=api；真实适配层没有导入 mock。服务层保留显式 mock 模式供演示和测试。未注册路由 Pricing.tsx 仍使用 mock 数据。API 可调用不等于 DTO 和全部操作已完成真实登录联调，不能宣称全部页面已验收。
